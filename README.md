# Market Bot

Market Bot 是一个面向全球市场的开放式交易平台。平台允许用户发布和购买商品，并通过开放 API 让人工智能（AI）搜索商品、比较信息、加入购物车以及在授权规则内完成下单。

## 当前状态

首期交易闭环已在模块化单体中落地：身份/卖家/商品、购物车与订单、支付沙盒与 Webhook 幂等、数字交付与实物发货、卖家结算、AI 授权与自动下单、审核、以及买家/卖家 Web 页面。运行时仍使用内存适配器；PostgreSQL / Redis / 对象存储通过 Docker Compose 和迁移文件预留，生产支付与首发区域评估尚未完成。

## 产品定位

Market Bot 的长期目标是支持数字商品、实物商品、服务和其他合法商品类型，并同时服务普通用户和能够调用平台 API 的 AI 代理。

首期只开放两类商品：

- 数字商品：文件、卡密、兑换码或授权链接，支付成功后自动交付。
- 标准实物商品：有明确规格、库存、发货地区和配送方式的商品，由卖家发货并同步物流状态。

任何注册用户都可以成为卖家。平台通过基础账号验证、商品检查、交易记录、举报和风控机制维护交易质量。

## 技术基线

- 前端：Next.js、React、TypeScript
- 后端：Rust stable、Tokio、Axum
- 数据库：PostgreSQL
- 缓存与限流：Redis
- 商品搜索：OpenSearch
- 文件和数字商品：S3 兼容对象存储、CDN
- 异步处理：事务消息外发机制和云消息队列
- 部署：Docker 和云托管容器服务
- 监控：OpenTelemetry、集中式日志、指标和链路追踪

后端采用**模块化单体 + API 优先**架构。前期保持一个主要业务系统，内部按领域模块隔离；当搜索、支付、交付或 AI 访问量达到独立扩展条件时，再拆分对应服务。

## 核心业务原则

1. AI 可以搜索和加购，但加入购物车本身不产生付款。
2. AI 自动下单必须由用户主动开启，并受到商品类别、卖家条件、价格和金额限额约束。
3. 下单前必须重新确认库存、价格、运费和税费。
4. 订单、支付、库存和交付状态分别管理，并且所有关键操作可审计。
5. PostgreSQL 是订单、库存、支付和结算数据的最终数据源。
6. 平台不保存银行卡完整信息，支付和卖家结算通过合规支付服务商完成。
7. 金额使用货币最小单位整数保存，禁止用浮点数处理金额。
8. 首期按区域逐步开放，不以一次性覆盖所有国家作为上线条件。

## 首期不开放

首期暂不开放拍卖、订阅商品、复杂服务预约、账号交易、多卖家合并订单、自建物流网络和平台自行托管用户资金。
